# lexical-analyzer-flex

A lexical analyzer built with Flex (Lex) and C++. It reads source code from `input.txt` and prints each token with its category.

## Token categories
- Keywords: control flow, declaration/type, access/modifier, concurrency/exception, module/import
- Single-line (`//`) and multi-line (`/* */`) comments
- Boolean (`true`, `false`) and null (`null`, `nullptr`) literals
- Identifiers and function calls (e.g. `main()`, `printf("...")`)
- Integer and float numbers
- Assignment, relational and logical operators
- Delimiters `( ) { }` and symbols `, ; :`
- `#include` library files
- String and character literals

## Files
- `scan.l` — Flex specification (rules)
- `lex.yy.c` — C++ source generated by Flex from `scan.l`

## Build and run
```bash
flex scan.l
g++ lex.yy.c -o lexer
./lexer        # reads input.txt from the current directory
```
On Windows the compiled program is `a.exe` when built with `g++ lex.yy.c`.
